# 02: 新 cfg 格式、轉移舊 cfg，偵測螢幕並擷取成「預設」模式

**What to build:** 程式能用 Windows 顯示設定 API 偵測目前接上的每台螢幕（廠牌、型號、序號、接孔、目前狀態、支援的解析度與更新率），並以「廠牌 + 型號 + 序號」辨識螢幕，讀不到序號時改用「廠牌 + 型號 + 接孔」（ADR-0003）。cfg 改為 INI 分段格式，存放一般設定、模式與每個模式的螢幕設定，程式整份重寫並附中文註解。第一次以新版啟動時，若讀到舊格式 cfg，先備份為 `.bak`，轉移仍有意義的值（自動切換、滑鼠移動門檻、聲音音量門檻、聲音持續秒數、忽略遠端輸入、通知），捨棄其餘；開機啟動狀態從登錄檔沿用。cfg 不存在或為舊格式時，以擷取目前螢幕狀態建立「預設」模式。工作列選單新增「將目前螢幕狀態存入〈目前模式〉…」，確認後擷取並存檔。此階段切換仍沿用舊有方式，尚不依模式套用。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 啟動後 cfg 為新格式，內含「預設」模式，每台接上螢幕的開關、座標、解析度、更新率、方向、主螢幕與實際狀態一致
- [ ] 舊格式 cfg 被備份為 `.bak`，指定的值正確轉移
- [ ] 擷取規則：接上且開啟的螢幕記錄完整狀態；接上但關閉的螢幕記錄為關閉並保留原有解析度/更新率（沒有則用原生解析度）；記錄過但沒接上的螢幕保持不變
- [ ] 從工作列擷取前會跳確認視窗，確認後存入目前模式
- [ ] 測試涵蓋：cfg 寫出再讀回結果相同、舊格式轉移與備份、首次啟動建立「預設」模式、三類螢幕的擷取規則、螢幕識別在有序號/無序號時的組成
- [ ] 手動實測：同型號螢幕、換接孔時識別結果符合 ADR-0003
