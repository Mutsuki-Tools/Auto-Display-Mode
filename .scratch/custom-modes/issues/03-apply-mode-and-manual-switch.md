# 03: 用 Windows API 套用模式，從工作列手動切換任何模式

**What to build:** 程式改用 Windows 顯示設定 API 套用模式的螢幕設定（ADR-0002），不再需要 bat 與 MultiMonitorTool（從工作目錄移除）。工作列選單列出所有模式，目前模式打勾、切換中顯示提示，點一下即手動切換。套用規則：模式中記錄但沒接上的螢幕略過；接上但未記錄的螢幕依該模式的「未記錄的螢幕：維持現狀/關閉」設定（預設維持現狀）；若結果沒有任何螢幕開著則拒絕套用並通知。套用失敗時維持原本的模式、跳出錯誤通知、自動切換暫停 1 分鐘。每個模式有「手動切換進入此模式時，自動切換要維持/開啟/關閉」設定（預設維持）與工作列圖示顏色；圖示以目前模式的顏色繪製，實心表示自動切換開、空心表示關。切換進行中再次手動切換時提示「正在切換中」。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 在 cfg 手動新增第二個模式並重新載入後，可從工作列選單在兩個模式間切換，螢幕實際改變
- [ ] bat 與 MultiMonitorTool 不再被使用，並已從工作目錄移除
- [ ] 工作列圖示顏色隨目前模式改變，實心/空心反映自動切換
- [ ] 測試涵蓋：沒接上的螢幕略過、未記錄螢幕維持現狀/關閉、全部關閉時拒絕、主螢幕與座標正確輸出、套用失敗維持原模式與 1 分鐘暫停、手動切換的維持/開啟/關閉三種設定、切換中拒絕重複切換
- [ ] 手動實測：拔掉一台螢幕後切換仍正常；直向螢幕方向正確
