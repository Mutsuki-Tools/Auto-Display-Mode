# 05: 設定視窗骨架與一般設定

**What to build:** 雙擊工作列圖示或從選單選「設定…」開啟設定視窗（只允許開一個）。視窗底部有「確定/取消/套用」：修改先暫存在視窗內，按套用或確定才寫入 cfg，取消則放棄。設定視窗開著時暫停自動切換，工作列的「重新載入 cfg」暫時停用。本票建立「一般設定」分頁：滑鼠移動門檻、聲音音量門檻、聲音持續秒數、忽略遠端輸入、自動切換通知、開機登入時自動開啟。開機啟動以 cfg 為準，程式每次啟動時將登錄檔 Run 機碼同步為 cfg 的值與目前 exe 路徑（不需系統管理員權限）。工作列選單整理為最終內容（目前模式、各模式、自動切換、設定…、存入目前模式…、用記事本開啟 cfg、重新載入 cfg、說明、關閉程式），並更新說明內容，介面文字一律使用 `GLOSSARY.md` 的用語。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 設定視窗可從雙擊圖示與選單開啟，再次開啟時帶到前景而非開第二個
- [ ] 一般設定各欄位修改後按套用即寫入 cfg 並立即生效；按取消不改變任何東西
- [ ] 設定視窗開著時不發生自動切換，且「重新載入 cfg」停用
- [ ] 開機啟動勾選與 cfg、登錄檔一致；exe 搬家後重開程式，登錄檔路徑自動更新
- [ ] 測試涵蓋：設定視窗開啟時暫停自動切換、開機啟動依 cfg 同步、一般設定儲存後讀回相同
