# 06: 模式分頁

**What to build:** 設定視窗新增「模式」分頁，使用者可新增、刪除、重新命名、複製模式。名稱不可空白或重複；新增模式自動配一個未使用的顏色。刪除模式前跳確認，列出會一併刪除的切換條件（來源或目標是該模式者）；最後一個模式與目前模式不可刪除。重新命名不影響切換條件。每個模式可設定圖示顏色、「手動切換進入此模式時，自動切換要維持/開啟/關閉」、「未記錄的螢幕：維持現狀/關閉」。提供「以目前螢幕狀態覆蓋此模式」與「以目前螢幕狀態新增模式」，結果先暫存，按套用/確定才存檔；存入的模式隨即成為目前模式並重新計時。

**Blocked by:** 03, 04, 05

**Status:** ready-for-agent

- [ ] 可在分頁中完成模式的新增、刪除、重新命名、複製，並反映到工作列選單
- [ ] 刪除確認會列出連帶刪除的切換條件；最後一個與目前模式無法刪除且說明原因
- [ ] 擷取到非目前模式並套用後，目前模式改為該模式，工作列圖示隨之更新
- [ ] 測試涵蓋：刪除時連帶刪除切換條件、最後一個與目前模式不可刪、名稱不可空白/重複、重新命名不影響條件、複製產生獨立的螢幕設定、擷取後目前模式變更與計時歸零
