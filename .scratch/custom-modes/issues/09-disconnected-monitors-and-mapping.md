# 09: 未接上的螢幕清單與手動對應

**What to build:** 螢幕配置分頁的畫布旁新增「未接上的螢幕」清單，列出目前編輯的模式中記錄過、但現在沒接上的螢幕。每一項可「刪除」該筆螢幕設定，或「對應到…」一台目前接上但此模式未設定的螢幕，讓換上同型號新螢幕時能沿用舊設定（ADR-0003）。畫布上標示「此模式未設定」的接上螢幕。

**Blocked by:** 08

**Status:** ready-for-agent

- [ ] 拔掉一台螢幕後開啟設定視窗，它出現在「未接上的螢幕」清單中
- [ ] 刪除後該筆螢幕設定從模式中移除
- [ ] 「對應到…」後，舊螢幕設定改套用到選定的新螢幕，原記錄移除
- [ ] 此模式未設定的接上螢幕在畫布上有明顯標示
- [ ] 測試涵蓋：對應後螢幕設定轉移到新識別、刪除未接上螢幕的螢幕設定
