## Comments

### 2026-11-21 實作完成（待手動實測）

使用者覺得原本的說明視窗內容太多太雜，提議拆到各設定畫面。討論後決定的方案就是本票。

#### 設定視窗

- `SettingsPage` 新增抽象屬性 `HelpText`，四個分頁各自提供說明。
- 設定視窗底部改成兩欄的表格：
  - 左邊是「說明」按鈕。
  - 右邊是原本的「確定」「取消」「套用」。按鈕列要設 `WrapContents = false`，否則在自動寬度欄中會被擠成直排。
- 「說明」與 F1（`OnHelpRequested`）顯示目前分頁的說明，標題為「Auto Display Mode - 說明：分頁名稱」。說明開著時再按 F1 不會疊出第二個。
- 用一個共用按鈕，不在每個分頁各放一個：位置固定，也不必改動四個分頁的版面。

#### 內容分配

- **模式**：管理模式、調整順序與重新編號、刪除限制；套用模式時的規則（沒接上的螢幕略過、未記錄的螢幕、拒絕切換與失敗暫停 1 分鐘、手動切換進入時的自動切換）；分頁內的兩個擷取按鈕。
- **螢幕配置**：原本【螢幕配置】段落，分成畫布、選取的螢幕、檢查、未接上的螢幕、預覽套用。
- **切換條件**：原本【自動切換】段落，分成切換條件、條件、計時、無法套用。補上「新增」「刪除」與表格編輯。「掛鉤子」改寫成「監聽鍵盤滑鼠輸入」，因為對使用者來說比較好懂。
- **一般設定**：每個設定的意思與怎麼調整，不列數值。
  - 「滑鼠移動門檻」寫明只用在「偵測到使用」：實際上只有鉤子看這個門檻，閒置計時看的是 Windows 的最後輸入時間。
- **右鍵選單的「說明」**：工具在做什麼、模式與切換條件是什麼、目前模式與自動切換開關、右鍵選單每一項的用途（包括「目前：…」與「說明」本身）、圖示、cfg 的位置。
  - 拿掉「目前的切換條件」清單與一般設定的數值。
  - 右鍵選單的擷取留在這裡說明，模式分頁的說明則講分頁內的擷取按鈕。

#### 檢查

- 沒有改到核心，214 個測試照常通過；建置 0 警告、0 錯誤。
- 以拋棄式小程式在 150% 下開啟真正的設定視窗：
  - 「說明」在左下角，「確定」「取消」「套用」在右下同一列。
  - 四個分頁的說明視窗內容與標題正確；螢幕配置分頁是用 F1 開啟的。
- 右鍵選單的說明只是 MessageBox 的文字，沒有另外截圖。

#### 審查後的修正

- 「沒接上的螢幕」統一為 GLOSSARY 的「未接上的螢幕」。
- 「其他螢幕的座標跟著平移」改為「其他開啟的螢幕」：關閉的螢幕座標不變。
- 「桌子震動」改為「桌面震動」，與分頁上的提示一致。遠端輸入的設定名稱補上「偵測到使用時，」，與核取方塊一致。
- 模式的定義補上「從它出發的切換條件在「切換條件」分頁設定」。
- 右鍵選單的說明補上「目前：…」「說明」兩項，擷取那一行補上「並重新開始計時」。
- 底部按鈕列的初始化不再先設再覆蓋。F1 防止重複開啟；`OnHelpRequested` 補上 doc 註解。
- 判斷題，沒有修改：
  - 說明與分頁上的提示有幾句相近。說明是讓人一次看完的整理，提示是放在欄位旁的短句，用途不同，所以沒有抽成共用字串。
  - 說明中的「10 秒」「1 分鐘」「15 秒」是寫死的數字，對應核心的私有常數。這是沿用舊說明的寫法。
  - 模式分頁另立【擷取】段，雖然畫面上沒有叫「擷取」的區塊：擷取是 GLOSSARY 的用語，兩個按鈕都寫著「以目前螢幕狀態…」。

#### 手動實測步驟

1. 從工作列關閉正在執行的舊版程式，執行 `build.bat`，再啟動新的 exe（這張票不會修改 cfg）。
2. 右鍵選單選「說明」：只有開頭的總說明、目前模式與自動切換、【右鍵選單】【圖示】【cfg】，沒有各分頁的操作細節。
3. 開啟設定視窗：左下角有「說明」，右下角的「確定」「取消」「套用」在同一列；4K、150% 的螢幕上沒有被切掉。
4. 依序切到四個分頁，按「說明」：標題是「Auto Display Mode - 說明：分頁名稱」，內容是該分頁的說明。
5. 在任一分頁的欄位中按 F1，同樣顯示該分頁的說明；說明開著時再按 F1，不會跳出第二個。
