# 01: 切換條件的「強制」欄位、設定視窗小改進、建置輸出改到 release 資料夾

**What to build:** 切換條件新增「強制」欄位：勾選後，即使自動切換關閉、設定視窗開著，這條也照樣生效（使用者故事 21、22）。同時改進設定視窗：切換條件分頁的「鍵盤滑鼠」與「聲音」兩欄等寬（35）；有未套用的變更時顯示提醒（36），關閉前先確認（37）。另外，之後執行檔會帶著驅動檔等依賴，所以建置輸出從專案根目錄改到新的 `release/` 資料夾（使用者要求）。這張票與虛擬螢幕無關，可以先做。

**Blocked by:** 無

**Status:** ready-for-agent

- [ ] 切換條件分頁多一欄「強制」（核取方塊，預設不勾），cfg 的 `[Switch.N]` 以 `Forced=1|0` 儲存並有註解；舊 cfg 沒有這個欄位時當成 0
- [ ] 自動切換關閉時，只檢查有勾強制的切換條件；檢查順序仍照編號
- [ ] 設定視窗開著時，有勾強制的切換條件照樣生效，沒勾的照舊暫停；切換後設定視窗維持開啟，編輯中的副本不受影響（目前模式以協調者為準，見 `ApplySettings`）
- [ ] 鉤子需求跟著調整：會被檢查的條件中有「偵測到使用＋鍵盤滑鼠」時才安裝鉤子
- [ ] 「鍵盤滑鼠」與「聲音」兩欄等寬（目前 `FillWeight` 是 88 和 45）
- [ ] 有未套用的變更時，下方按鈕列「說明」右邊顯示「有尚未套用的變更」，套用成功後消失
- [ ] 有未套用的變更時，按「取消」或 ✕ 先問「要放棄尚未套用的變更嗎？」；選否就留在設定視窗
- [ ] `build.bat` 把 exe 輸出到 `release/AutoDisplayMode.exe`，不再複製到專案根目錄；`drivers/sudovda/` 的驅動檔、公開憑證與授權聲明一併複製到 `release/drivers/sudovda/`（票 02 起程式從這裡找驅動檔；這張票先做好複製即可）
- [ ] cfg 跟著 exe：以 `git mv` 把 `AutoDisplayMode.cfg` 移到 `release/`，維持納入 git；`release/` 中其他檔案（exe、驅動檔的複本）不進 git
- [ ] 刪除專案根目錄的舊 exe；開機啟動在新 exe 第一次啟動時會改寫成新路徑（`SyncStartup`），手動實測確認
- [ ] 文件與說明中提到 exe、cfg 位置的地方都改成 `release/`
- [ ] 切換條件分頁的說明、cfg 註解、右鍵選單的說明都補上強制的意思
- [ ] 測試：強制條件在自動切換關閉、設定視窗開著時的行為，以及鉤子需求；cfg round-trip
- [ ] 手動實測
