# 03: 遠端模式、內建切換條件與復原模式

**What to build:** 新增遠端模式（使用者故事 1～20、30、33），以及復原模式的記錄、程式啟動時的復原（28），和虛擬螢幕意外消失時的處理（29）。核心新增「虛擬螢幕」介面，Windows 轉接層以 SudoVDA 的 IOCTL 實作（做法依票 02 的結果）；偵測螢幕時排除本程式建立的虛擬螢幕。驅動的安裝與移除已在票 02 完成。

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] 模式分頁有「新增遠端模式」；複製遠端模式得到遠端模式；一般模式和遠端模式不能互相轉換；清單上看得出哪些是遠端模式
- [ ] 遠端模式的設定：名稱、圖示顏色、手動切換進入時的自動切換、虛擬螢幕解析度與更新率（下拉選單，預設 1920×1080@60）；不顯示「未記錄的螢幕」
- [ ] 螢幕配置分頁選到遠端模式時，不顯示畫布，改顯示說明
- [ ] 「以目前螢幕狀態覆蓋此模式」對遠端模式停用；「以目前螢幕狀態新增模式」一律建立一般模式；處於遠端模式時，右鍵選單和分頁中的擷取都停用並說明原因
- [ ] 最後一個一般模式不能刪除
- [ ] 每個遠端模式剛好一條內建切換條件：新建時加在清單最後、不能刪除、可以拖動；條件、使用來源、強制都鎖定，只能選目標（只能選一般模式）；遠端模式刪除時一起刪除
- [ ] 內建切換條件的目標失效時，改成順序第一個一般模式，並在套用時提示
- [ ] 內建切換條件一律只認實體鍵盤滑鼠，不受「忽略遠端連線軟體送出的鍵盤滑鼠輸入」影響
- [ ] 進入遠端模式時，先建立虛擬螢幕再關閉所有螢幕；離開時，先開啟螢幕再移除虛擬螢幕；遠端模式之間切換時，只換解析度
- [ ] 驅動不可用或建立失敗時，拒絕切換並通知，維持原本的模式
- [ ] 驅動不可用時，模式分頁中遠端模式旁顯示警告與「安裝驅動」按鈕（原票 05，使用者故事 34）
- [ ] 處於遠端模式時，從介面執行緒持續送心跳
- [ ] 協調者記錄復原模式（切換到一般模式時更新，重新編號時跟著改）；程式啟動時若目前模式是遠端模式，就改套用復原模式；復原模式不存在時，使用備案
- [ ] 虛擬螢幕意外消失時，切回復原模式並通知
- [ ] 偵測、擷取、套用、畫布都排除本程式建立的虛擬螢幕，其他虛擬顯示照舊
- [ ] cfg：`RestoreMode`、`Kind`、`VirtualWidth`／`VirtualHeight`／`VirtualRefreshRate`、`BuiltIn`，加上註解；讀取時驗證內建切換條件，不符就修正並提示
- [ ] 各分頁的說明與右鍵選單的說明，補上遠端模式、內建切換條件與復原模式
- [ ] 測試：spec Testing Decisions 中與遠端模式、內建切換條件、復原模式、cfg 相關的行為
- [ ] 手動實測：用 Chrome 遠端桌面實際連線，進入遠端模式、在電腦前動滑鼠回到一般模式、遠端模式之間切換、拒絕切換
