# 05: 虛擬螢幕驅動的安裝與移除

**What to build:** 在設定視窗中安裝與移除內附的 SudoVDA 驅動（使用者故事 31、32、34），步驟依票 02 驗證過的做法。安裝與移除都以提權的子程序執行，主程式維持一般權限。

**可攜性（使用者要求）：** 成品 exe 複製到其他電腦後，必須能自己幫新使用者安裝與移除驅動。所以驅動檔（`.inf`、`.dll`、`.cat`）與公開憑證要**內嵌在 exe 中**，安裝時解壓到暫存資料夾；安裝流程只能用 Windows 內建的 API 或工具（例如 SetupAPI／`UpdateDriverForPlugAndPlayDevices` 建立裝置節點、`X509Store` 匯入憑證），不能依賴 WDK、devcon、nefcon 或其他另外下載的程式。建議用同一個 exe 加參數（例如 `--install-driver`）以系統管理員身分重新啟動自己來執行。

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] 設定視窗（建議放在一般設定分頁）顯示驅動狀態：未安裝、已安裝、無法使用
- [ ] 「安裝驅動」：跳出 UAC，匯入公開憑證到「受信任的根憑證」與「受信任的發行者」，建立裝置節點並安裝 INF；完成後狀態更新
- [ ] 「移除驅動」：跳出 UAC，移除裝置節點與驅動，並刪除安裝時匯入的憑證；處於遠端模式時不能移除
- [ ] 使用者取消 UAC 或安裝失敗時，顯示原因，狀態維持不變
- [ ] 驅動不可用時，模式分頁中遠端模式旁顯示警告與「安裝驅動」按鈕
- [ ] 驅動檔與公開憑證內嵌在 exe 中；只把 exe 複製到另一台沒有開發工具的電腦，也能安裝、使用、移除驅動
- [ ] 安裝與移除只用 Windows 內建的 API 或工具
- [ ] 說明補上驅動的安裝、移除，以及為什麼需要系統管理員權限
- [ ] 手動實測：在乾淨狀態下安裝、使用遠端模式、移除，確認憑證也被刪除
