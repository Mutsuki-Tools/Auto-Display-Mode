# 模式編號跟著模式的順序，套用設定時重新編號

切換條件與目前模式以「模式編號」（cfg 中 [Mode.N] 的 N）指向模式。原本編號建立後就不變，但使用者在設定視窗調整模式順序後，希望 cfg 的編號也依新順序排列。我們決定讓編號跟著順序：在設定視窗按「套用」時，模式依清單順序重新編號為 1、2、3…，切換條件的來源與目標模式、目前模式（包括視窗中擷取的模式）跟著改；寫入 cfg 成功後，設定視窗的副本也用同樣的方式重新編號。改名不影響編號；刪除模式留下的空號也在套用時補齊。

編號只在套用時改變，所以編輯中的副本、協調者記錄的目前模式，在套用前都使用同一套編號；套用在切換中會被拒絕，不會有進行中的切換仍指向舊編號。介面上不能以編號長期保留選取：模式分頁依位置保留，螢幕配置分頁以模式物件保留。

## Considered Options

- 編號永遠不變，只改 cfg 中各段的順序：不必同步任何東西，但 cfg 會出現 [Mode.3]、[Mode.1]… 的順序，與使用者看到的順序不一致。
- 每次調整順序就立即在副本中重新編號：協調者記錄的目前模式仍是舊編號，套用前兩邊不一致，從工作列手動切換也會對不上。
