# 內附自行編譯、自簽的 SudoVDA 作為虛擬螢幕驅動

潛行模式需要在 Windows 上產生一個沒有實體顯示器的畫面，這一定要有簽章過的間接顯示驅動（Indirect Display Driver），無法只靠程式本身做到。使用者要求不依賴其他軟體（Parsec、Apollo 等可能被移除），而且程式閃退時虛擬螢幕必須自動消失。我們決定內附 SudoVDA：它的驅動端有心跳保險（一段時間沒收到程式的心跳就移除所有虛擬螢幕），新增、移除虛擬螢幕不需要系統管理員權限，建立時可指定解析度，授權（MIT／CC0）允許內附。

SudoVDA 沒有官方發行版，因此由我們從原始碼編譯，以一張拋棄式自簽憑證簽章，簽完即刪除私鑰；repo 只保存簽好的驅動與公開憑證，安裝時匯入「受信任的根憑證」與「受信任的發行者」。私鑰已不存在，這張根憑證無法再被用來簽其他東西。代價是安裝驅動要系統管理員權限一次、要裝 WDK 才能重新編譯，而且每次更換驅動版本都要換一張新憑證。

## Considered Options

- Parsec Virtual Display Driver：心跳保險最快（約 1 秒），但驅動是 Parsec 的產品、無法內附，也不符合「不依賴其他軟體」；與 Parsec 本體同時控制驅動時，還會互相移除對方的虛擬螢幕。
- Virtual-Display-Driver（MttVDD）：有正式簽章、持續維護，但沒有心跳保險，程式閃退後虛擬螢幕會留著（重開機後還會再出現），而且要讓它完全消失只能停用裝置，需要系統管理員權限。
- 直接取用 Apollo 安裝檔中的 SudoVDA：免編譯，但要信任 SudoMaker 的根憑證，等於信任該金鑰簽過的任何東西。
- 自行開發驅動：需要 EV 憑證與微軟簽署，個人工具不可行。
