# 以分層機制在意外結束時切回復原模式

處於遠端模式時，所有螢幕都關閉；本程式一旦意外結束，坐在電腦前的人會看不到任何畫面。使用者要求不論程式自行結束、閃退、被強制結束、被作業系統關閉或斷電，都要立即切回復原模式，而不是等下次啟動。單一機制做不到，因此分層處理：

1. 程式自行結束，以及關機、登出、重開機時收到工作階段即將結束的通知：程式自己先套用復原模式再結束。
2. 閃退、被強制結束或介面卡住：進入遠端模式時，另外啟動一個守護程式，監看主程式的存活與心跳；主程式不是正常結束，或心跳逾時，就由守護程式套用復原模式。
3. 主程式與守護程式都失效：驅動的心跳保險（ADR-0005）會移除虛擬螢幕，Windows 再以它記住的「只有實體螢幕」配置點亮螢幕。這份配置通常就是剛套用過的復原模式，但不保證。
4. 斷電：當下無法處理；開機時沒有程式建立虛擬螢幕，實體螢幕自然點亮，程式開機啟動時若目前模式是遠端模式，就改套用復原模式。

程式還在執行、但虛擬螢幕被系統移除（睡眠喚醒、顯示卡驅動重置）時，同樣切回復原模式並通知，不自動重建虛擬螢幕。

## Considered Options

- 只在程式下次啟動時復原：最簡單，但閃退後到重新啟動前，電腦前的人看不到任何畫面。
- 只靠驅動心跳保險與 Windows 的配置記憶：不需要守護程式，但 Windows 不保證還原成復原模式，也有實體螢幕維持黑畫面、要按 Win+P 才恢復的案例。
- 以 Windows 服務當守護程式：服務在工作階段 0 執行，無法改變使用者工作階段的螢幕配置。
