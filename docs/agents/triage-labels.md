# Triage 標籤

各 skill 以五個標準 triage 角色來描述狀態。本檔將這些角色對應到本專案 issue tracker 實際使用的標籤字串。

| mattpocock/skills 中的標籤 | 本專案使用的標籤   | 意義                               |
| -------------------------- | ------------------ | ---------------------------------- |
| `needs-triage`             | `needs-triage`     | 需要維護者評估此 issue             |
| `needs-info`               | `needs-info`       | 等待回報者提供更多資訊             |
| `ready-for-agent`          | `ready-for-agent`  | 規格完整，可交給無人值守的 agent   |
| `ready-for-human`          | `ready-for-human`  | 需要由人來實作                     |
| `wontfix`                  | `wontfix`          | 不會處理                           |

當 skill 提到某個角色（例如「套用 AFK-ready 的 triage 標籤」）時，使用上表中對應的標籤字串。

若實際使用的詞彙不同，請修改「本專案使用的標籤」欄。
