# Auto Display Mode 使用說明

Auto Display Mode 是一個常駐在工作列（右下角通知區）的小工具。它能在你設定好的幾組螢幕配置之間切換，例如「三台螢幕全開」「只開一台」「全部關閉、只留給遠端用」。切換可以手動，也可以讓它依你有沒有在使用電腦自動進行，例如離開 5 分鐘就只留一台、一動滑鼠就全部打開。

---

## 資料夾裡的檔案

| 檔案 | 用途 |
|---|---|
| `AutoDisplayMode.exe` | 程式本身，雙擊就能執行，不需要安裝 |
| `AutoDisplayMode.cfg` | 你的設定。第一次執行時才會產生，之後由程式自動維護 |
| `drivers\` | 「潛行模式」用的虛擬螢幕驅動。不用潛行模式的話可以不管它，但請不要刪除 |
| `README.md` | 這份說明 |

這些檔案要放在同一個資料夾裡。要搬移的話，請**整個資料夾一起搬**。

## 系統需求

- Windows 10 或 Windows 11（本程式用的 .NET Framework 4.8 已內建在 Windows 中，不必另外安裝）。
- 潛行模式已在 Windows 11 上測試過。

---

## 開始使用

1. 雙擊 `AutoDisplayMode.exe`。
   - 如果跳出「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。這是因為本程式沒有向微軟購買簽章，不是病毒。
2. 右下角通知區會出現一個彩色的小螢幕圖示。如果沒看到，點一下通知區的「^」把隱藏的圖示展開。
3. 第一次執行時，程式會把你**目前**的螢幕狀態存成一個叫「預設」的模式。
4. 在圖示上按**右鍵**，就能看到所有功能。

### 圖示的意思

- **顏色**：目前所在的模式（每個模式可以自訂顏色）。
- **實心**：自動切換開著。**空心**：自動切換關著。
- 滑鼠停在圖示上，會顯示目前的模式與自動切換狀態。

### 右鍵選單

| 項目 | 用途 |
|---|---|
| 目前：… | 顯示目前所在的模式（不能點） |
| 模式清單 | 點一下就切換到那個模式（打勾的是目前的模式） |
| 自動切換 | 開關自動切換 |
| 設定… | 開啟設定視窗，在這裡新增模式、排螢幕位置、設定切換條件 |
| 將目前螢幕狀態存入「…」 | 把現在的螢幕狀態直接存進目前的模式（例如你剛在 Windows 的顯示設定裡調整好） |
| 用記事本開啟 cfg／重新載入 cfg | 進階：直接修改設定檔，存檔後要按「重新載入 cfg」才會生效 |
| 說明 | 程式內建的說明 |
| 關閉程式 | 結束程式 |

## 基本觀念

- **模式**：一組有名字的螢幕設定，記錄每台螢幕要開或關、放在哪裡、解析度與更新率。例如「全開」「單螢幕」。
- **切換條件**：「在 A 模式時，如果發生某件事，就切換到 B 模式」的規則。可以用的條件有兩種：
  - **閒置**：一段時間沒有使用電腦，例如 5 分鐘沒動鍵盤滑鼠、也沒有播放聲音。
  - **偵測到使用**：一有人使用就切換，例如一動滑鼠。
- **自動切換**：所有切換條件的總開關。關掉後，只有勾了「強制」的切換條件還會作用。

## 設定視窗

從右鍵選單選「設定…」開啟。所有修改都要按「套用」或「確定」才會生效；有還沒套用的修改時，視窗下方會提醒你。每個分頁都可以按左下角的「說明」（或按 F1），看這一頁的詳細說明。

- **模式**：新增、複製、刪除、改名、調整順序，設定每個模式的顏色等。
- **螢幕配置**：像 Windows 的顯示設定一樣，用拖拉的方式排列每台螢幕，設定開關、解析度與更新率。
- **切換條件**：設定什麼情況下自動切換到哪個模式。
- **一般設定**：開機登入時自動開啟、偵測使用的靈敏度、通知，以及潛行模式要用的驅動。

### 建議的第一步

1. 先在 Windows 的「設定 → 系統 → 顯示器」把螢幕調成你要的樣子。
2. 在右鍵選單選「將目前螢幕狀態存入…」，或在設定視窗的「模式」分頁按「以目前螢幕狀態新增模式」，存成一個模式。
3. 重複以上步驟，做出幾個不同的模式。
4. 到「切換條件」分頁，設定「閒置多久切到哪個模式、一動滑鼠切回哪個模式」，再打開自動切換。

## 潛行模式

潛行模式會**關閉所有螢幕**，只留下一個看不到的「虛擬螢幕」，電腦本身照常運作。

**適合用在：**

- **遠端連線**：例如從外面用 Chrome 遠端桌面連回家裡的電腦。遠端看到的是虛擬螢幕，家裡的螢幕全部關著，解析度可以自己選，不受實體螢幕影響。
- **省電**：螢幕全部關閉，顯示卡的負擔也比較小。不過省電效果比不上讓電腦睡眠，它的好處是遠端仍然連得進來。

**注意：** 「潛行」只是指螢幕全暗，**不是防窺**。坐在電腦前的人只要動一下滑鼠或鍵盤，螢幕就會馬上亮回來。

### 第一次使用要先安裝驅動

虛擬螢幕需要一個驅動程式，它就在 `drivers` 資料夾裡，安裝一次就好：

1. 開啟設定視窗 → 「一般設定」分頁。
2. 按「安裝驅動」，跳出「使用者帳戶控制」時按「是」。
3. 狀態顯示「已安裝」就完成了。

安裝時，除了驅動本身，也會在電腦裡加入這個驅動的憑證（用來證明驅動檔案沒被竄改）。移除驅動時會一起刪掉。

### 建立潛行模式

1. 設定視窗 → 「模式」分頁 → 「新增潛行模式（虛擬螢幕）」。
2. 選擇虛擬螢幕的解析度與更新率，例如配合遠端用的筆電或手機。
3. 按「套用」。

之後就能像一般模式一樣，從右鍵選單手動切換過去，或用切換條件自動切換，例如「閒置 10 分鐘切到潛行模式」。

### 怎麼離開潛行模式

- **人在電腦前**：動一下滑鼠或按一下鍵盤，就會回到一般模式。這條規則是每個潛行模式內建的，不能刪除，自動切換關著時也有效。遠端連線送來的操作不算，所以遠端時不會被踢出去。
- **遠端時**：從右鍵選單切換到其他模式。

### 萬一程式出問題

就算程式當掉、被強制結束、電腦關機或停電，螢幕也會自動亮回來：

- 程式正常關閉、或 Windows 關機和登出時，程式會先把螢幕切回來再結束。
- 程式當掉或卡住時，另一個小小的守護程式會在幾秒內把螢幕切回來。
- 就算兩個程式都不在了，虛擬螢幕也會在幾秒後自動消失，Windows 會把螢幕點亮。
- 停電後重新開機時，螢幕本來就會亮；程式啟動後也會回到一般模式。

**如果螢幕還是一直黑著**：按鍵盤的 **Win + P**，選「延伸」或「僅電腦螢幕」。還是不行的話，重新開機就會恢復。

## 搬到其他電腦

1. 把**整個資料夾**複製過去（包括 `drivers` 資料夾）。
2. 設定檔記錄的是原本那台電腦的螢幕。換到新電腦時，建議刪掉 `AutoDisplayMode.cfg`，讓程式依新電腦的螢幕重新建立。
3. 要用潛行模式的話，在新電腦上按一次「安裝驅動」。

## 解除安裝

1. 用過潛行模式的話：設定視窗 →「一般設定」→ 按「移除驅動」（會一起刪除當初加入的憑證）。
2. 有勾「開機登入時自動開啟」的話，先在「一般設定」取消勾選並套用。
3. 從右鍵選單「關閉程式」。
4. 刪除整個資料夾。

本程式沒有安裝程式，也不會在其他地方留下檔案。除了上面兩項，Windows 只會在開機自動執行的清單中留下一個項目，取消勾選「開機登入時自動開啟」就會移除。

## 常見問題

**螢幕切換時會閃一下或暗幾秒，正常嗎？**
正常。開關螢幕時，Windows 需要幾秒鐘重新設定顯示畫面。

**切換後視窗跑到別的螢幕上了？**
這是 Windows 的行為：螢幕被關掉時，上面的視窗會被移到還開著的螢幕。

**設定視窗的「虛擬螢幕驅動」顯示「找不到驅動檔」？**
`drivers` 資料夾沒有跟 `AutoDisplayMode.exe` 放在一起。請把整個資料夾一起搬。

**通知太多？**
在「一般設定」可以關閉自動切換時的通知。

## 給開發者

原始碼的根目錄有 `build.bat`，它會建置並測試程式，再把程式、驅動與這份說明輸出到 `release` 資料夾。`release` 資料夾整個刪掉，也能用 `build.bat` 重新產生（設定檔除外，程式第一次執行時會自己建立）。需要 [.NET SDK](https://dotnet.microsoft.com/download)。
